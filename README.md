# Konnen Electrical Website

Static marketing website for **Konnen Electrical LLC**.

## Pages

- `index.html` — Home
- `capabilities.html` — Capabilities
- `about.html` — About
- `contact.html` — Contact / estimate request preview

## Brand system

- Charcoal / slate foundation
- Copper accent
- Restrained sage / stone neutrals
- Two-terminal connection motif
- Subtle topographic references
- Core positioning: knowledge, planning, skilled execution, reliable delivery
